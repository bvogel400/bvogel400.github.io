🌐 Final Project: Interactive Web Experience

Combining HTML, CSS, and JavaScript

🧭 Overview

Your final project is the culmination of everything you’ve learned throughout this course—from building semantic web pages with HTML to styling them with CSS, and adding dynamic, interactive behavior with JavaScript. The goal is to create an interactive and engaging website that demonstrates your mastery of all core concepts taught in class.

To meet this challenge, a single idea (such as a basic game or form) is not enough. You are expected to combine multiple features into a cohesive project or significantly expand a single idea to include a variety of technical components.

🎯 Learning Goals

Your final project must showcase your ability to:

✅ HTML

  • Use semantic HTML elements properly (<header>, <nav>, <article>, <section>, etc.)

  • Organize multi-page or single-page dynamic content with clean structure

✅ CSS

  • Style your site using external CSS

  • Use Flexbox and/or other layout techniques

  • Create responsive design using media queries

  • Apply consistent and creative visual styling (fonts, colors, spacing, etc.)

✅ JavaScript

  • Write and use functions, arrays, objects, loops, and conditionals

  • Respond to events (click, input, submit, etc.)

  • Manipulate the DOM dynamically (change content, add/remove elements)

  • Perform form validation and manage user input

  • Use JSON and/or localStorage to save and retrieve data

📦 Project Requirements

Your project must include:

  • ✅ HTML pages: At least 3 HTML pages or a dynamic SPA-style interface

  • ✅ CSS Styling: Consistent and responsive design using Flexbox and/or media queries

  • ✅ JavaScript:

    • Event handling

    • DOM manipulation

    • Dynamic content updates

  • ✅ A functional HTML form with JS validation

  • ✅ Data usage with JSON and/or localStorage

  • ✅ A working navigation system (links or menu)

  • ✅ Deployment via GitHub Pages

  • Input form for expenses with validation

  • Rock-Paper-Scissors + Guess the Number + Memory Match

  • Unified navigation and styling

  • Store scores with localStorage

  • Form for player name and game selection

📚 Study Buddy Dashboard

  • Quiz app with JSON-based questions

  • Flashcard section (HTML + JS toggle behavior)

  • Timer for study sessions

  • Save quiz scores in localStorage

🍔 Recipe Book + Ingredient Search + Submission Form

  • Dynamic display of recipes (from local JSON)

  • Filter recipes by type or ingredient

  • User form to submit a new recipe (validate input)

  • Save new recipes to localStorage

🖼️ Digital Art Gallery + Like/Comment System

  • Gallery view using Flexbox grid

📊 Final Project Grading Rubric (Total: 100 Points)

Category Points Criteria
HTML Structure & Semantics 15 - Correct use of semantic HTML elements (<header>, <section>, <nav>, etc.)- Clean and accessible structure- Organized and readable HTML
CSS Styling & Layout 15 - Consistent and creative styling- Use of Flexbox or equivalent layout- Responsive design using media queries
JavaScript Functionality 20 - Includes well-structured JS code using functions, arrays, conditionals, and loops- Handles DOM manipulation effectively- Uses event listeners for interactivity
Form & Validation 10 - Includes at least one form- Validates input with JavaScript- Prevents default actions and gives clear feedback
Data Handling (JSON / localStorage) 10 - Uses JSON data (external or hardcoded)- Stores/retrieves data using localStorage where appropriate
Project Completeness 10 - Covers all major course components- Combines features meaningfully- Demonstrates course-wide understanding
Code Quality & Comments 10 - Code is clean, organized, and readable- Includes comments explaining logic- Follows good practices (indentation, naming, structure)
Creativity & Originality 5 - Thoughtful design- Unique idea or creative feature integration
User Experience (UX) 5 - Smooth and intuitive navigation- Clear feedback to user actions- No major bugs or visual issues
Presentation & Deployment 5 - Project is hosted on GitHub Pages- GitHub repo includes a complete README.md- Zipped file submitted to Brightspace (see below)

🔁 Bonus Points (Up to +5 points)

  • Integration with an external API

  • Use of animations, dark mode, or other creative UI enhancements

  • Special focus on accessibility (ARIA roles, keyboard navigation, etc.)
