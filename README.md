# Brendan Vogel - Final Project Portfolio

## Project Description
This project is a personal portfolio website that combines HTML, CSS, and JavaScript.

## Team / Roles
- Brendan Vogel

## Feature Summary
- Multi-page navigation:
  - Home: `index.html`
  - Resume: `channels/project_resume.html`
  - Hobbies: `channels/project_hobbies.html`
  - About: `channels/project_about.html`
  - Contact: `channels/contact.html`
- Semantic HTML structure (`header`, `nav`, `main`, `section`, `article`, `footer`)
- External CSS styling in `styles.css`
- Responsive layout with Flexbox/Grid and media queries
- JavaScript functionality:
  - Theme toggle with localStorage persistence
  - Active navigation highlighting
  - JSON data loading from `scripts/projects.json`
  - Dynamic DOM rendering of projects
- Form and validation:
  - Contact form in `channels/contact.html`
  - Validation with clear error messages and submit feedback
  - Prevented default submission behavior
- Data handling:
  - JSON used for project data
  - localStorage used for theme and contact submission history

## Course Concepts Demonstrated
- HTML semantics and accessible navigation
- Consistent and responsive CSS design patterns
- JavaScript functions, arrays, objects, loops, conditionals, events, and DOM manipulation
- Form validation and user feedback flows
